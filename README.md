### What We Build

**GadoHost** gives developers, indie makers, and web agencies a single high-speed NVMe cloud panel to deploy modern web stacks without managing Linux servers manually:

| Stack | Included Capabilities |
| :--- | :--- |
| **WordPress & PHP 8.1 – 8.4** | 1-Click WordPress install, passwordless WP-Admin SSO, isolated PHP-FPM pools, visual `php.ini` editor, OPcache flush |
| **Node.js 18 – 24 & Next.js** | Zero-downtime PM2 clusters, automated `npm install` + production build, Git deployment webhooks, real-time log streaming |
| **MySQL 8 & MongoDB 7** | Isolated databases included on every plan, 1-Click phpMyAdmin auto-login, SCRAM-SHA-256 MongoDB clusters |
| **Security & Dev Experience** | Automatic Wildcard & Let's Encrypt SSL, kernel-isolated SFTP/SSH sandbox, 1-Click full site + DB `.tar.gz` backups, business domain emails |

### Starter Templates & Open-Source Tools

- **[nextjs-mongodb-starter](https://github.com/gadohost/nextjs-mongodb-starter)** — Production Next.js + MongoDB boilerplate ready to deploy on GadoHost in 15 seconds.
- **[nodejs-express-starter](https://github.com/gadohost/nodejs-express-starter)** — Lightweight Express.js REST API preconfigured for PM2, health checks, and MySQL/MongoDB.
- **[php84-mysql-starter](https://github.com/gadohost/php84-mysql-starter)** — Clean PHP 8.4 PDO + MySQL starter template with Nginx/FastCGI best practices.
- **[gadohost-deploy-action](https://github.com/gadohost/gadohost-deploy-action)** — GitHub Actions workflow template for automatic Git push deployments via GadoHost Webhooks.
